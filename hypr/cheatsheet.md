# Hyprland Cheatsheet — Keybinds

## Lanzadores

- SUPER + T: kitty
- SUPER + E: thunar
- SUPER + B: brave-browser
- SUPER + V: clipboard
- SUPER + Y: wallpaper
- SUPER + TAB: overview

## Tema y color

- SUPER + SHIFT + T: aplicar tema

## Seguridad

- SUPER + ALT + L: lock
- SUPER + SHIFT + E: logout
- SUPER + SHIFT + R: reload config
- SUPER + SHIFT + Q: kill Hyprland
- SUPER + SHIFT + X: suspend
- SUPER + SHIFT + H: hibernate

## Audio

- XF86AudioRaiseVolume: subir volumen
- XF86AudioLowerVolume: bajar volumen
- XF86AudioMute: mute
- XF86AudioMicMute: mute mic
- XF86AudioPause: pausa
- XF86AudioPlay: play/pause
- XF86AudioPrev: anterior
- XF86AudioNext: siguiente

## Brillo

- XF86MonBrightnessUp: subir brillo
- XF86MonBrightnessDown: bajar brillo

## Capturas

- SUPER + SHIFT + S: región
- CTRL + Print: pantalla completa
- ALT + Print: ventana activa
- Print: región

## Navegación y gestión

- SUPER + Q: cerrar ventana
- SUPER + F: fullscreen
- SUPER + H/J/K/L: mover foco
- SUPER + SHIFT + H/J/K/L: mover ventana
- SUPER + U/I: cambiar workspace
- SUPER + SHIFT + U/I: mover ventana a workspace

## Cheat sheet

- SUPER + SHIFT + Ñ: mostrar este cheat sheet

---

Para más detalles, revisa KeyBind.conf.
